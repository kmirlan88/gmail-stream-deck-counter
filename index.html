How it works

The counter runs locally on its owner’s Mac. Google sign-in connects the Gmail account, and the tool checks unread category counts periodically. This website provides information about the tool; it does not connect to Gmail.

Read-only access

Google’s read-only Gmail permission enables category searches. The counter requests message identifiers to calculate counts. It does not retrieve email bodies or attachments, and does not send, change, or delete messages.

Read the privacy policy for details about permissions, local storage, and removing access.
