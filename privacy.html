Privacy policy

Gmail Stream Deck Counter is a personal macOS utility maintained by Mirlan Kaiyrbaev. It displays unread Gmail counts on an Elgato Stream Deck.

Google data access and use

The tool requests gmail.readonly, Google’s read-only Gmail permission, to search for unread messages in the Primary, Promotions, and Social categories. It requests message identifiers and pagination information to calculate unread counts.

The implementation does not fetch message bodies, subjects, senders, attachments, or message settings. It does not send, modify, or delete email. Google’s permission description is broader than the subset of operations this tool uses.

Storage and protection

OAuth refresh tokens and client configuration are stored in the macOS user’s Keychain. Access tokens and unread counts are kept in process memory. Message identifiers are used while counting and are not intentionally saved to files.

Local connection-status logs contain mailbox category, connection state, error code, and HTTP status. They exclude credentials, unread counts, and email content. The log rotates after approximately 512 KB, retaining one previous file.

Sharing and transfers

Requests go directly from the Mac to Google’s OAuth and Gmail services over HTTPS. Gmail data is not sold, used for advertising, used to train AI models, or sent to analytics providers or third-party application servers.

Use of information received from Google APIs is limited to the unread-count functionality described here and adheres to the Google API Services User Data Policy, including its Limited Use requirements.

This informational website

This website does not participate in Google sign-in or receive Gmail data. It uses no analytics scripts, forms, advertising, or application cookies. It is hosted on GitHub Pages. GitHub may process visitor IP addresses and technical request information to operate and secure its hosting service, as described in the GitHub Privacy Statement.

Removing access and local data

Use Disconnect in the Stream Deck action settings to remove the locally saved refresh token. Revoke the tool’s Google access at any time through Google Account connections.

Local diagnostic logs can be deleted from ~/Library/Logs/GmailOAuthCounter. Disconnect does not delete client configuration or diagnostic logs. Saved client configuration can be removed from the macOS Keychain under the service com.mirlan.gmail-oauth-counter.

Contact and updates

For questions, use the developer contact shown on the tool’s Google consent screen or visit the developer’s GitHub profile. Changes to this policy will be published here with an updated date.
